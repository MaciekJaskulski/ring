# Ring home configurator – UX prototype

Clickable, responsive prototype of the Ring home configurator (doorbell, camera, doorbell + camera, alarm) with the UX fixes applied: stage stepper, removed "main concern" questions, sticky CTAs, mobile result without the house canvas, fullscreen Zoe on mobile, upsell flow ("Add a camera / doorbell") and carousel of alternatives.

Run locally:

```bash
python3 -m http.server 8765
```

Open http://localhost:8765 and use "Prototype menu" (top bar) to jump to any result screen or to Zoe.

Product data is sample data based on the live en-uk configurator; the house image is hotlinked from the Zoovu CDN. Zoe is UI only.
